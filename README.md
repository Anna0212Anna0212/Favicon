# 圖標工坊｜線上圖片裁切與網站圖標製作工具

**圖標工坊**是一款免安裝的線上圖片處理工具，專為網站開發者、程式設計初學者及需要製作個人化圖標的使用者設計。使用者可以直接在瀏覽器中匯入圖片，進行背景移除、形狀裁切、尺寸調整與視覺美化，並匯出適合網站使用的圖標及完整素材套組。
主要是用ai生成出來的網頁圖標，時常會有出錯，自己修改又很費力，這個就完美解決了✅

## 主要功能

- **圖片匯入與主體擷取：** 支援拖曳上傳、選擇檔案及貼上剪貼簿圖片，提供魔術棒去背、自動去背與多種裁切工具。
- **自由裁切：** 支援方形、圓角矩形、圓形、橢圓形及自由點選，讓使用者依照需求調整圖片範圍。
- **尺寸與位置調整：** 可縮放、旋轉、調整四邊留白、移動圖像位置，並預覽主體是否超出圖標範圍。
- **背景與視覺美化：** 支援透明背景、純色背景、漸層背景、圓角、描邊、陰影、外光暈及多種濾鏡。
- **即時預覽：** 提供圖標預覽、瀏覽器分頁模擬，以及不同尺寸和深淺背景的顯示效果。
- **多格式匯出：** 支援 PNG、ICO、SVG（內嵌點陣圖）、WebP 及 JPG，並可選擇輸出尺寸。
- **網站素材套組：** 一鍵產生 Favicon、Apple Touch Icon、Android Chrome 圖標、網站 Manifest 與 HTML 引用程式碼，並打包成 ZIP 檔案。
- **編輯輔助：** 提供復原、還原原圖、取消選區及複製 HTML 引用碼等功能。

## 使用特色

- **免安裝：** 開啟網頁即可使用。
- **重視隱私：** 圖片處理在使用者的瀏覽器中進行，不需將圖片上傳至自建伺服器。
- **操作直覺：** 將裁切、編輯、預覽及匯出整合在同一個介面。
- **適合網站開發：** 協助使用者快速製作網站圖標及常見的網站圖像素材，減少手動調整尺寸與整理檔案的時間。

## 適用情境

1. 製作個人網站或 GitHub Pages 專案的 Favicon。
2. 將 AI 生成的圖片裁切成合適的網站圖標。
3. 為程式專案、個人品牌或網頁設計製作專屬圖標。
4. 快速產生多種尺寸的圖片，並整理成可直接使用的網站素材套組。

**圖標工坊讓圖片從匯入、裁切、美化到匯出一次完成，讓網站素材製作更方便、更有效率。**
